# SOH-CAH-TOA Trainer

An interactive web app for practicing right-triangle trigonometry. Built to help study for dual-credit precalculus.

## What it does

- Generates random right-triangle problems and quizzes you on solving for a missing side or angle using SOH-CAH-TOA
- Three difficulty levels: Easy (find a side), Medium (find an angle), Hard (mixed, with decimals)
- Draws a live SVG diagram of the actual triangle for each question, so you can visualize the problem instead of just reading numbers
- Tracks your score across a 5-question round
- Optional hint button for each question

## How to use it

Download `trig_quiz_web.html` and open it in any browser — no installation, no server, no dependencies. Pick a difficulty and start solving.

## Built with

Plain HTML, CSS, and JavaScript — no frameworks or libraries required.

## Why I built this

I wanted a study tool for dual precal that actually shows the triangle instead of just presenting numbers, and it doubles as a first project for learning to build interactive web tools.
